## 🛠️ Technical Stack & Features

- **Semantic HTML5:** Structured with standard accessibility-compliant tags (`<header>`, `<nav>`, `<section>`, `<main>`, `<time>`, `<footer>`).
- **Modern Responsive CSS:** Structured using mobile-first **Flexbox** and **CSS Grid** to adapt dynamically from mobile (375px) to wide desktops (1200px+).
- **Vanilla JavaScript:** Fast, lightweight scripts for:
  - Sticky header shadow transitions.
  - Active navigation page tracker on scroll.
  - Interactive mobile navigation drawer toggle.
  - Simulated contact form validation and submission notifications.
- **Embedded Vector SVGs:** Symmetrical icons and decorative patterns rendered directly in the HTML to minimize load latency and HTTP requests.

## 🎨 Design System

- **Primary Theme:** Minimalist engineering precision.
- **Color System (Harmonious Teal & Slate):**
  - Background: Off-white (`#F7FAFC` / `#FFFFFF`)
  - Primary Text & Borders: Charcoal Slate (`#2D3748`)
  - Accent Color: Muted Steel Blue (`#4A5568`)
  - Tech Indicator: Muted Teal (`#319795`)
  - Active State Dot: Crimson red notification pulse for floating widgets.
- **Typography:** Modern clean system sans-serif stack (`system-ui`, `-apple-system`, `Roboto`, `Arial`).
